# Pagination Open Questions

**Date:** 2026-11-03
**Review by:** 2027-02-01
**Status:** Active

## Open Questions

1. Should MediaVault eventually replace the plain-array response with a
   page-envelope containing result-count metadata?

2. When should frontend pagination controls be added?

3. Should collection endpoints eventually use the same pagination contract?

## Current Guidance

These questions are deliberately deferred.

They should not prevent completion of the current media-item controller
pagination work. Existing active pagination decisions remain authoritative
until one of these questions is intentionally resolved and recorded as a new
or superseding project decision.
