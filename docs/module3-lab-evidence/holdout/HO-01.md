**Lesson: Preserve the Plain-Array Pagination Contract**

- **What happened:** MediaVault needed server-side pagination, but existing consumers expected the response to be a plain JSON array.
- **What was learned:** Pagination can be added gradually with optional `page` and `size` parameters. The response doesn't have to switch to a page envelope right away.
- **Future application:** When controller pagination is implemented, both of these should hold:
  - Requests that omit both parameters still return the full list.
  - The response stays a plain array until someone approves a deliberate change to the API contract.

**Related project decision:** `.memory/project/decisions/decision-002.md` records the same backward-compatible contract: optional `page`/`size` parameters and the existing plain-array response.
