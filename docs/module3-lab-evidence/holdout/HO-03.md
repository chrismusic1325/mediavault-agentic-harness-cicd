**What happened:** Pagination needed a consistent order of results and protection against very large page sizes (lines 9–12).

**What was learned** (lines 16–18):
- Use parameterized `LIMIT ? OFFSET ?`.
- Cap the requested page size with `MAX_PAGE_SIZE = 100`.
- Compute large offsets safely.
- When the primary sort field isn't unique, add `id` as a secondary sort key so the order stays the same every time.
