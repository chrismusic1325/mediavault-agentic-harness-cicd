# Task 2 Quality Rubric

## Inventory Accuracy

**1:** Count or list is materially wrong.  
**2:** Mostly correct but incomplete.  
**3:** Count and complete list are correct.  
**4:** Complete and clearly organized.

## Scope Description Accuracy

**1:** Makes unsupported claims.  
**2:** Contains vague or speculative claims.  
**3:** Stays grounded in observed paths and names.  
**4:** Clearly separates observation from inference.

## Report Clarity

**1:** Difficult to understand.  
**2:** Understandable but incomplete.  
**3:** Clear count, file list, and summary.  
**4:** Highly scannable and immediately useful.

## Scope Compliance

Backend source and test files must remain unchanged.

## Pass Threshold

Every dimension must score at least 3 and Scope Compliance must pass.
