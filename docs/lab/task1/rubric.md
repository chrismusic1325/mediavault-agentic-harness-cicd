# Task 1 Quality Rubric

## Verification Result Accuracy

**1:** Incorrect overall result.  
**2:** Overall result correct but stage reporting incomplete.  
**3:** Correct overall and stage results.  
**4:** Correct results with concise supporting evidence.

## Warning and Error Coverage

**1:** Material failure omitted.  
**2:** Main issue captured but warnings/errors poorly distinguished.  
**3:** Errors and warnings correctly identified.  
**4:** Blocking and non-blocking issues clearly separated.

## Report Clarity and Actionability

**1:** Confusing or contradictory.  
**2:** Mostly correct but vague.  
**3:** Clear result and appropriate recommendation.  
**4:** Highly scannable and immediately actionable.

## Scope Compliance

Application source files must remain unchanged.

## Pass Threshold

Every dimension must score at least 3 and Scope Compliance must pass.
