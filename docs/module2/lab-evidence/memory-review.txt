## Unresolved pagination question

- Decision 004 says to "cap" the size at 100, and the stashed DAO clamps it silently.
- Decision 003 only defines `page < 0` and `size < 1` as invalid. It doesn't cover large sizes.
- Decision 003 also rejected silently ignoring a lone `page`/`size` because "the client could believe pagination occurred when the server actually returned the full list."
